# SWYNEX Task 4 - Final Data Science Project

## Project Title
Titanic Survival Prediction

## Project Overview
This project was completed as part of the SWYNEX Technologies internship, Task 4: Final Data Science Project.

The objective is to analyze the Titanic passenger dataset and build a machine-learning model to predict whether a passenger survived.

## Problem Statement
Passenger survival may be associated with factors such as age, gender, passenger class, and fare. This project explores these relationships and develops a baseline classification model.

- Seaborn
- Scikit-learn
- Google Colab

## Project Workflow
1. Loaded and inspected the prepared dataset.
2. Checked data types, missing values, and duplicate records.
3. Performed exploratory data analysis.
4. Created visualizations to examine survival patterns.
5. Prepared features and split the dataset into training and testing sets.
6. Trained a Logistic Regression model.
7. Evaluated performance using accuracy, precision, recall, F1 score, classification report, and confusion matrix.
8. Discussed model limitations and future improvements.

## Key Findings
The notebook examines:
- Survival distribution.
- Survival rates by gender.
- Survival rates by passenger class.
- Age and fare distributions across survival groups.
- Relationships among numerical features.

## Limitations
- Logistic Regression may not capture complex nonlinear relationships.
- Results depend on the available data and selected features.
- A single train-test split may produce different results from other splits.
- The historical Titanic dataset may not generalize to other populations.

## Future Improvements
- Compare additional models, such as Decision Tree and Random Forest.
- Use cross-validation.
- Explore feature engineering and further model tuning.
